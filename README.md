# RPBINDER

Десктопный биндер отыгровок для RP-серверов (GTA/SAMP и др.) — клон приложения
по предоставленным макетам. Профили, отыгровки, глобальные горячие клавиши,
автоввод сообщений в игровой чат, публичный каталог.

> Учебный/демо-проект. Использование автоввода в онлайн-играх может нарушать
> правила серверов — применяйте на свой риск и только там, где это разрешено.

## Стек

- **Electron** — десктоп-оболочка (окно без рамки, трей, single-instance).
- **React + TypeScript + Vite** (`electron-vite`) — интерфейс.
- **zustand** — состояние интерфейса.
- **electron-store** — локальное хранилище профилей и настроек.
- **uiohook-napi** — глобальные горячие клавиши (низкоуровневый хук, работает
  поверх игры). Опциональная нативная зависимость.
- **@nut-tree-fork/nut-js** — эмуляция клавиатурного ввода в активное окно.
  Опциональная нативная зависимость.

## Архитектура

```
src/
  shared/      типы и контракты IPC (общие для main и renderer)
  main/        main-процесс Electron
    index.ts   окно, трей, жизненный цикл
    ipc.ts     IPC-обработчики
    store.ts   хранилище (electron-store) + фабрики сущностей
    engine.ts  движок: активный профиль, привязка хоткеев, проигрывание
    hotkeys.ts глобальные хоткеи (uiohook-napi) + режим захвата комбинации
    typer.ts   автоввод в игровой чат (nut-js) с режимом dry-run
    catalog.ts публичный каталог (локальная реализация, готова к подключению API)
  preload/     contextBridge -> window.api (типобезопасный мост)
  renderer/    React-приложение
    components/ Chrome (титлбар, рейл, навигация, крошки), Toggle, Icons
    pages/      Profiles, ProfileEditor, OtygrovkaEditor, Catalog, Help, Settings
    store.ts    zustand-стор + навигация
```

### Нативные модули (важно)

Эмуляция ввода и глобальные хоткеи требуют нативных модулей и реально работают
**на Windows**. Они объявлены как `optionalDependencies` и подгружаются
динамически: если модуль не установился (например, при разработке на Linux/Mac),
приложение продолжает работать, а ввод выполняется в режиме **dry-run**
(действия только логируются). Это позволяет разрабатывать интерфейс на любой ОС.

### Каталог

Сейчас каталог отдаёт демо-данные из `src/main/catalog.ts`. Точка подключения к
реальному бэкенду — метод `catalog.fetchRemote()`; замените его тело на запрос к
вашему API, сохранив сигнатуру.

## Запуск

```bash
npm install        # установит зависимости (нативные — опционально)
npm run dev        # запуск в режиме разработки
npm run build:win  # сборка установщика под Windows (nsis)
```

## Статус

хранением, привязка хоткеев и движок проигрывания, автоввод с задержками,
